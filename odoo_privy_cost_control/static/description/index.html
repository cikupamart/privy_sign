Privy Digital Signature & Cost Control

Secure Odoo 18 Workflows with PrivyID & Smart Minimum Amount Thresholds

Optimalkan penggunaan kuota tanda tangan elektronik (TTE) PrivyID Anda di Odoo 18. Cegah pemborosan anggaran pada dokumen bernilai rendah melalui kontrol batas minimum otomatis, serta nikmati integrasi penuh di Invoice, Sales, dan Purchase.

Fitur Utama Unggulan

Cost Control Threshold

Validasi otomatis berbasis nilai minimum transaksi di menu Settings untuk menghentikan pengiriman dokumen kecil yang memboroskan kuota.

Multi-Module Support

Terintegrasi secara mulus di Customer Invoices (account.move), Sales Orders (sale.order), dan Purchase Orders (purchase.order).

Multi-Signer Routing

Atur urutan penandatangan internal perusahaan dan eksternal (klien/vendor) secara fleksibel langsung dari tab dokumen Odoo.

Otomatisasi Webhook & Laporan Analitik

Real-time Webhook Callback

Status dokumen diperbarui otomatis menjadi Signed atau Rejected, serta file PDF resmi bertanda tangan diunduh dan dilampirkan secara instan ke Odoo.

Privy Usage Pivot Report

Laporan rekapitulasi berbasis SQL View interaktif untuk memantau volume penggunaan kuota dan total nilai nominal transaksi yang diamankan.

Panduan Penggunaan Singkat

  1. Konfigurasi API: Masuk ke Invoicing > Configuration > Settings, masukkan Privy API Key, pilih Environment (Sandbox/Production), dan tetapkan batas minimum threshold.
  2. Aktifkan pada Dokumen: Buka Invoice, Sales Order, atau Purchase Order, centang opsi "Gunakan TTE Privy". Sistem otomatis memvalidasi batas minimum transaksi Anda.
  3. Kirim & Pantau: Klik tombol "Kirim ke Privy". Status dan dokumen PDF bertanda tangan akan disinkronkan secara otomatis melalui webhook.
